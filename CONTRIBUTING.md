# Contributing

Thanks for helping improve this list.

- One tool or resource per pull request, added to the section where it fits best, in alphabetical order after any recommended picks.
- Use the official link and a short, neutral one-line description.
- Entries must help students or teachers create, review, or export study material, and must be actively maintained.
- Format: `- [Name](https://link) - Description.`
- Please explain in the pull request what the tool does and why it fits, and disclose if you work on it.
- No affiliate or tracking links, no essay mills, and no pirated textbooks.

If this list is useful to you, a star helps other writers find it.
